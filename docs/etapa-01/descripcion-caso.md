# Descripción del Caso

## Problema que resuelve el sistema

El proyecto consiste en el diseño e implementación de una base de datos para una plataforma e-commerce destinada a la venta y gestión de indumentaria.

El sistema busca centralizar la información relacionada con los productos, sus variantes, clientes, ventas, compras a proveedores, pagos y stock, permitiendo organizar y mantener la información de las operaciones comerciales.

## Alcance del sistema

El sistema contempla la gestión de productos de indumentaria, categorías, talles, colores y stock de sus variantes.

También permite registrar usuarios, gestionar ventas y sus detalles, registrar los pagos asociados, administrar proveedores y registrar las compras realizadas para el abastecimiento de productos.

El sistema contempla además la conservación de los precios unitarios correspondientes a las operaciones de compra y venta, evitando que modificaciones posteriores de precios alteren el historial de las operaciones realizadas.

## Actores

### Cliente / Usuario
Se registra en el sistema, consulta los productos disponibles y realiza compras de indumentaria.

### Administrador
Gestiona la información de productos, categorías, variantes, stock, usuarios, ventas, pagos, proveedores y compras.

### Proveedor
Proporciona los productos de indumentaria que son adquiridos por el negocio para abastecer el stock.

## Operaciones principales

- Registro y gestión de usuarios.
- Gestión de productos y categorías.
- Gestión de talles y colores.
- Gestión de variantes de productos.
- Control y actualización del stock.
- Registro de ventas y sus detalles.
- Registro de pagos y métodos de pago.
- Registro de proveedores.
- Registro de compras a proveedores y sus detalles.
- Conservación del historial de precios unitarios de compra y venta.
